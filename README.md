# Design System v3.8

Static website prepared for GitHub Pages. No build step required.

## Publish
1. Create a GitHub repository (for example `design-system`).
2. Upload **the contents of this folder** to the repository root (not the outer ZIP/folder).
3. In repository Settings > Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Visit the URL GitHub provides, usually `https://USERNAME.github.io/design-system/`.

Open `index.html` to browse locally. All 10 outlet pages are linked from the homepage. All brand artwork is unchanged from v3.7. The theme toggle changes website backgrounds, not the underlying logo artwork. Fonts loaded from Google Fonts require an internet connection. Original source vector logos are not included, so SVG download links are marked unavailable rather than linking to missing files.
